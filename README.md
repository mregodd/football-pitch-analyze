# Football Pitch Analyzer

Transform short football broadcast clips (10–30 seconds) into structured 2D tactical minimaps.

## Phase 1 MVP

- Manual pitch calibration (4+ points)
- Player detection and tracking
- Top-down minimap video output
- Structured tracking data (tracks.parquet)

## Setup

```bash
pip install -e .
```

## Run

```bash
pitch-analyzer
```
